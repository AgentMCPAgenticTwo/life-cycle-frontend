1. Concurrent Redline Conflict (UC5)
Stops two reviewers from overwriting each other’s changes.
Works when: a reviewer submits changes on the latest version, and the changes are saved normally.
Blocks when: someone else submitted a newer version first.
Result: the message “A newer version was submitted… Please refresh and reapply your changes” appears, and both versions are saved.
5. Mandatory Clause Can’t Be Removed (UC3)
Works when: the user removes an optional clause, and it is removed.
Blocks when: the clause is mandatory.
Result: “This clause is mandatory and cannot be removed from the contract.”
13. Audit Log Can’t Be Changed (UC11)
Always blocked: editing or deleting a log entry.
Result: “Audit log entries cannot be modified or deleted.”
Condition: this is blocked in the UI, the API and the database.
